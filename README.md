# CardDrop — Black Cards & VIP Plastic (Telegram Mini App)

> **CardDrop** — премиальный Telegram Mini App коллекционной карточной финтех-тематики. Игроки выпускают эксклюзивные виртуальные банковские карты из различных материалов (Classic Plastic, Matte Plastic, Gold, Black Carbon, Titanium, Holographic) пяти игровых банков с редкими номерными узорами, собирают альбомы и соревнуются в рейтинге коллекционеров.

---

## ⚡ Особенности и функционал

1. **Генерация карт и математическая модель**:
   - Криптографически стойкий ГСЧ на стороне сервера (`crypto.randomInt`).
   - 5 вымышленных банков (по 20% каждый): *Алфа Банк, ЗверьБанк, ОзановБанк, Тинькоффи, ОООтмыв Банк*.
   - 6 материалов: Classic Plastic (45%), Matte Plastic (25%), Gold (12%), Black Carbon (10%), Titanium (6%), Holographic (2%).
   - 7 категорий узоров: Standard (70%), Pair (16%), Triple (6%), Quad (2%), Repeater (3%), Straight (2%), Mirror (1%).
   - Номер карты всегда начинается с `2202`, содержит 16 цифр, проверочный код коллекции и срок действия до 2100 г.
   - Стоимость стандартного выпуска: **500 Coins**.

2. **Функция автопрокрута (Auto-Roll)**:
   - Быстрый запуск серии от 1 до 100 выпусков карт на повышенной скорости.
   - Проверка баланса перед каждым выпуском.
   - При недостатке средств мгновенно останавливается с уведомлением «Недостаточно средств».
   - Итоговый отчёт о выпущенных картах и набранных очках.

3. **Бесплатный режим «БОМЖ»**:
   - Активируется автоматически, если баланс игрока **< 500 Coins**.
   - Стоимость: **0 Coins**.
   - Интервал (cooldown): **30 секунд**.
   - Лимит: **150 бесплатных выпусков в сутки**.
   - Специальные вероятности с коэффициентом удачи ×0.1.

4. **Коллекция и Альбомы**:
   - Автоматическая группировка по шаблонам (Банк + Материал + Категория).
   - Счётчик дубликатов (`×N`).
   - Фильтры по банку, материалу и категории.
   - Полноэкранный детальный просмотр с 3D-наклоном и голографическим переливом.
   - Добавление до 5 карт в избранное.
   - Возможность поделиться картой в Telegram.

5. **Ежедневные задания (до 500 Coins/день)**:
   - Вход в игру — 50 Coins.
   - Выпуск 3 карт — 150 Coins.
   - Задание дня — 300 Coins.

6. **Магазин Telegram Stars (валюта XTR)**:
   - Холдер карты (5 Stars)
   - Рамка профиля (10 Stars)
   - Эффект цифр (10 Stars)
   - Фон профиля (15 Stars)
   - Комплект оформления (25 Stars)
   - Идемпотентная выдача, проверка подлинности и поддержка `/terms` и `/paysupport`.

7. **Безопасность и отказоустойчивость**:
   - Полная криптографическая проверка HMAC-SHA256 подписи Telegram `initData`.
   - Идемпотентность всех транзакций по `requestId`.
   - Поддержка транзакций PostgreSQL с предотвращением отрицательного баланса.

## 🛠 Технологический стек

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, Canvas Confetti.
- **Backend**: Node.js, Express, TypeScript, tsx.
- **База данных**: PostgreSQL (Render Postgres) + ANSI SQL версионируемые миграции.
- **SDK**: Telegram WebApp JavaScript SDK с поддержкой Safe Areas, HapticFeedback и темы.
- **Тестирование**: Vitest (16 комплексных unit- и интеграционных тестов).

## 🚀 Запуск и разработка локально

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск тестов
```bash
npm test
```
*Все 16 тестов должны успешно выполниться.*

### 3. Сборка фронтенда
```bash
npm run build
```

### 4. Запуск сервера
```bash
npm start
```
Сервер запустится на `http://localhost:3000`.

## 🌐 Развёртывание на Render

Проект полностью настроен для развёртывания через **Render Blueprint**:

1. Загрузите репозиторий в ваш GitHub.
2. Откройте панель управления [Render Dashboard](https://dashboard.render.com).
3. Нажмите **New +** → **Blueprint**.
4. Выберите ваш GitHub репозиторий `black-cards-vip-plastic`.
5. Render автоматически создаст:
   - **PostgreSQL Database** (`black-cards-db`) с планом Free.
   - **Web Service** (`black-cards-vip-plastic`) со сборкой `npm install && npm run build` и стартом `npm start`.
6. В настройках переменных окружения Web Service добавьте:
   - `BOT_TOKEN`: токен вашего бота от `@BotFather`.
   - `NODE_ENV`: `production`.
   - `DATABASE_URL`: подставляется автоматически из базы данных.
7. После успешного деплоя скопируйте предоставленный HTTPS-домен (например, `https://black-cards-vip-plastic.onrender.com`).
8. В `@BotFather` укажите Mini App URL:
   - `/setmenubutton` → выберите вашего бота → укажите URL приложения.
